CV Analyzer

Overview
CV Analyzer is an intelligent tool designed to help recruiters and job seekers by analyzing resumes efficiently. Using natural language processing and machine learning, it extracts key details, matches skills to job descriptions, and provides insights to improve CV quality.

Features
- Automated Parsing: Extracts relevant details like experience, education, and skills.
- Skill Matching: Compares CV content with job descriptions for relevance.
- Scoring System: Ranks CVs based on predefined criteria.
- Suggestions: Provides recommendations for improvement.
- Multi-format Support: Works with PDF, DOCX, and TXT resumes.

Installation

- Clone the repository:git clone https://github.com/your-repo/cv-analyzer.git

- Install dependencies:pip install -r requirements.txt

- Run the application:python app.py


Usage

- Upload a CV file.
- Select job requirements (optional).
- Analyze and receive a detailed report.

Technologies Used

- Python
- Natural Language Processing (NLP)
- Machine Learning
- Flask (for Web Interface)
